Privacy Policy

Last updated: October 18, 2026

"map-answer" is a private analytics tool used only by the owner of the YouTube channel The Map Answer. It is not offered to other users.

What it accesses

With the owner's permission, it uses the YouTube Analytics API with read-only access (yt-analytics.readonly) to read view counts, watch time, audience retention and subscriber changes for the owner's own channel.

How the data is used

The figures are saved as summary statistics in the owner's private storage and used only to plan and improve the channel's videos. The data is not sold, shared with third parties, or used for advertising.

Retention and removal

Access can be revoked at any time in Google Account settings (Security → Third-party connections). Stored statistics are deleted when no longer needed.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
